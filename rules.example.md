Writing rules (example; copy to rules.md and edit, rules.md is git-ignored; this text is sent with every drafting task)
- Use only facts from the evidence bank. If a fact is not there, write nothing about it.
- Never invent employers, titles, dates, numbers or tools. Unknown stays Unknown.
- One page, plain headings, bullets that start with a verb, no tables, no images.
- Name your location and work-eligibility only if the evidence bank states them.
- Every document is a draft until a person checks every claim against the evidence.
